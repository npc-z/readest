# 本地化与文案

Type: grilling

## Question

讲解功能的 UI 文案与本地化：

- 文案清单：菜单项标签（"讲解"）、面板标题/级联按钮（"还看不懂？"/"词句帮助"/"母语译文"）、历史列表操作（重新生成/删除）、讲解库页标题与空态、toast（未配 AI 引导、超限截断、生成失败）——形成 key 列表登记。
- readest i18n 采用"英文 key 即内容"模式（`public/locales/<lng>/translation.json`）：定 en/zh 两种语言文案，其余约 30 种 locale 回退 en（确认这与现有实践一致）。
- 讲解正文的语言（L / M）不依赖 UI 语言（M=生成时快照），i18n 只管理 UI 外壳。
- 哪些文案属于共享既有 key（如"重新生成"是否已有现成 key）。

Blocked by: 04, 08

Status: resolved

## Answer

B 票定版：

- **范围**：仅提交 **zh-CN** 翻译；其余 ~35 语言（含 zh-TW）由 i18next 默认回退英文 key（与现有实践一致，社区按需补译）。
- **Key 登记**（en key = 文案；zh-CN 值见下表；含评审修订 Grammar · 2026-09-02，共 20 条）：

| Key | zh-CN |
|---|---|
| `Explain` | 讲解 |
| `Explain text after selection` | 讲解选中的文本 |
| `Explanation` | 讲解 |
| `Simple version` | 简单版 |
| `Word and phrase help` | 词句帮助 |
| `Native translation` | 母语译文 |
| `Grammar` | 语法要点 |
| `Still not clear?` | 还不懂？ |
| `Current` / `All` | 当前 / 全部 |
| `Regenerate` | 重新生成 |
| `Delete this explanation?` | 确定删除这条讲解吗？ |
| `Explanation library` | 讲解库 |
| `Select text in a book and click "Explain" to add an explanation here.` | 在书中选中文本并点击"讲解"即可收录到这里 |
| `Search explanations` | 搜索讲解 |
| `This book only` | 仅本书 |
| `Only explained the first 500 words` | 仅讲解了前 500 词 |
| `Nothing to explain` | 没有可讲解的文本 |
| `AI is not configured. Go to AI settings.` | 未配置 AI，前往设置 |
| `Failed to explain. Retry` | 讲解失败，点击重试 |
| `Explaining…` | 正在讲解… |

- **服务层文案**：文案只活在 UI 层——服务/route 返回错误码（`ai-not-configured` / `timeout` / `provider-error` / `no-object-salvaged` / `invalid-input` 等），UI 按码映射 key；服务无 i18n 依赖，不使用 stubTranslation。
- **复用**：`Delete`、`Search`、`Load more`、`Back to library`（若存在）直接复用；删除确认不用图书复数确认键，用新 key `Delete this explanation?`；toast/inline 风格与现有一致。
