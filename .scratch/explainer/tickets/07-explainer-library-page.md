# 07: 讲解库管理页 + 库页入口

**What to build:** 管理与回顾的第二个出口——从库页头部进入独立"讲解库"页：按时间浏览全部讲解、搜索、按单书筛选、点条目跳回书中对应位置，并可重新生成/删除。与面板的本书历史视图独立，跨书聚合。

**Blocked by:** 03 服务层：getOrGenerate + AI 通路（直连/route 分流），04 级联组件 + explainerStore（数据契约）

**Status:** ready-for-agent

- [ ] 页面：独立路由页 + 库页头部入口；数据直连服务层（Web/原生同一模式，无需专用接口）
- [ ] 列表：时间倒序、分页 20/页 + 加载更多；搜索（text LIKE，转义特殊字符）；仅本书筛选；行 = 原文首行 + 书标题/时间/层级徽标；行展开卡片复用级联组件（compact 变体）；区分卡片组件供面板 compact 与页面 expanded 复用
- [ ] 操作：重新生成（覆盖同一缓存键；错误 toast + 行内重试）；删除（确认后移除）；未配置 AI 空态引导
- [ ] 跳转：有 cfi → 打开书并定位段落（annotation-link 机制）；无 cfi → 仅打开书；失败 fail-soft 并 toast
- [ ] 三态：空（含未配置引导）/加载/无结果
- [ ] 测试：页面行为（列表/搜索/筛选/分页/删除/重新生成）断言外部行为，不测实现细节；组件测试复用级联 fixture 先例
