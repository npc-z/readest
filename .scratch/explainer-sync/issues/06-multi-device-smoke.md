**What to build:** 用两台真实设备（或同机两套 profile / 两个账号无关的本地 profile）人肉验证跨设备讲解同步的完整闭环。自动测试覆盖纯逻辑，本票覆盖只有真机才能验证的路径：登录、网络、compose 后端、本地库在多端的一致。

**Blocked by:** 04

**Status:** ready-for-human

- [ ] A 生成讲解 → B 选中同一段直接命中（无新的 AI 请求）
- [ ] B 的讲解库页出现 A 生成的条目，搜索与"仅本书"筛选结果一致
- [ ] A 删除 → B 同步后消失，且后续同步不复活
- [ ] A 重新生成 → B 更新为一条（不是两条）
- [ ] A / B 离线各自讲解同一段 → 联网后合并为一条
- [ ] 未登录或"讲解"类别关闭时，本地生成与浏览完全不受影响
- [ ] 自托管 `docker/compose.yaml` 栈无需新增服务即可同步（迁移 023 自动生效）

注：记录实测环境（平台、后端、账号）与任何偏差；偏差回写到对应实现票或 `../spec.md` 的 Decisions。
